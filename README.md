# 学习测验

手机 / 平板优先的个人刷题器。主体包括 **333 主观题** 与 **333 四科选择题**，支持普通练习、错题复习、收藏、笔记和限时测验。

## 当前功能

- 题型可分开选择：**选择题** / **简答与论述题** / 全部题型
- 选择题支持 A/B/C/D 作答、自动判分、答案解析、错题复习
- 主观题支持输入关键词骨架，再查看参考答案并自评“会 / 模糊 / 不会”
- 333 四科选择题采用**均衡抽题**：教育学原理 / 中国教育史 / 外国教育史 / 教育心理学轮流取题，避免单科刷屏
- 随机模式加入“最近做过的题冷却”：优先抽最近没有出现过的题
- **限时测验：按 2 分钟 / 道选择题计时**；例如 10 题 20 分钟、20 题 40 分钟
- 限时测验过程中不公布答案，交卷后统一统计正确率、实际用时、平均用时和未作答数
- 到时自动交卷，未作答题目会进入后续错题 / 不会题复习范围
- 按科目、顺序或随机抽题，自定义每轮题量（1～30 题）
- 只练错题 / 模糊 / 不会，或只练收藏题
- 收藏题目，并单独练习收藏题
- 每道题可写个人笔记，自动保存在本机
- 保存作答、评分、笔记、收藏和轮次记录
- 完成一轮后可生成 GitHub Issue 报告给 ChatGPT；限时报告会附带用时与未作答信息
- 首页可补交“今天全部记录”
- 可导出本机学习记录 JSON 作为备份

## 选择题来源

当前已加入四科均衡的丹丹题库批次，并保留 `source`、章节和真题 / 模拟标签。题目与解析采用题册和对应解析册配对后导入；无法可靠一一配对的内容不会强行写入标准答案。

仓库同时保留：

- `questions/custom-choice.json`：自定义选择题
- `questions/custom-subjective.json`：自定义简答 / 论述题
- `questions/dandan-batch-principles-1.json`
- `questions/dandan-batch-chinese-1.json`
- `questions/dandan-batch-foreign-1.json`
- `questions/dandan-batch-psychology-1.json`

网页载入时会按“题型 + 科目 + 规范化题干”自动去重，因此同一道真题来自多个资料时不会因为重复导入而反复出现。

## 选择题数据格式

```json
{
  "id": "choice-001",
  "type": "choice",
  "subject": "中国教育史",
  "number": 1,
  "title": "题目标题",
  "options": {
    "A": "选项A",
    "B": "选项B",
    "C": "选项C",
    "D": "选项D"
  },
  "answer": "C",
  "explanation": "答案解析",
  "source": "来源",
  "chapter": "章节",
  "set": "真题或模拟"
}
```

## 本地运行

由于浏览器不允许 `file://` 页面读取 JSON，请在仓库目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 更新原始 333 主观题库

题库数据由规范化 EPUB 自动提取：

```bash
python3 scripts/extract_questions.py /path/to/333主观200题.epub questions
```
